## 三、硬约束

### 3.1 数据层（家族回收）

| # | 约束 | 错误来源 |
| --- | --- | --- |
| H1 | 复合主键表裸 `SELECT *` 必须 `ORDER BY rowid` | 肠癌 parity ③ |
| H2 | 手写倒序数组只 `ORDER BY ord`，不叠加 DESC | 肠癌 parity ③ |
| H3 | 可选字段显式写 `null`，读模型按 `=== null` 判定 | 肠癌 parity ③ |
| H4 | 化验 / 体征 2–4 周一点并延续到当天；影像 / 内镜按真实频率，不加密 | 家族约定 |
| H5 | 看法恒不为结论；更正只新增版本；四点位缺健侧不生成差值（NULL≠0） | 四条契约 |
| H6 | 生成器列数必须与 `schema/*.sql` 逐一核对（位置式 INSERT 曾连续 6 次列数不匹配） | 胃癌轮次 F |
| H7 | 迁移只增不改；0001 冻结后新结构走 0002 | 家族约定 |

### 3.2 前端（家族回收）

| # | 约束 | 错误来源 |
| --- | --- | --- |
| H8 | 图标 key 必须有别名兜底 + 最终兜底，防 `<path d="undefined">` | 肠癌截图 |

| H12 | 对象字面量不许重复键（后者静默覆盖前者） | 胃癌轮次 F |

### 3.3 本轮实际踩到、已修（新晋硬约束）

| # | 约束 | 错误来源（本轮） |
| --- | --- | --- |
| H17 | **`views.*` 的默认分支必须带 `if (sub === N)` 条件，并以 `return ''` 收尾**。曾因默认分支裸 `return`，导致「肛周皮肤 → 分级记录」渲染出「建议联系医疗团队」整段错位 | 本轮二级页签错位（4 个视图） |
| H18 | **二级页签的顺序要与标题一一对应**：`labs` 曾把「血常规与生化」和「肿瘤标志物」两段 sub 判断写反 | 本轮实测 |
| H19 | **一图秀右侧必须预留末点标签宽度**（R=120），事件标题不进画布、只在左侧「治疗事件」栏；分类层整体下移到绘图区之外 | 本轮首版末点被裁切、事件标题互相压字 |
| H20 | **分类卡的值与单位不可重复**：`valueText = "0 级"` 时 `unitText` 必须为空，否则出现「0 级 分级 0/4」 | 本轮截图 |
| H21 | **「最近事件」按日期排序，不依赖数组顺序**（曾用 `slice(-5).reverse()`，录入顺序一变就错） | 本轮实测 |
| H22 | **导航计数只统计该页真正管理的东西**：`life` 曾把造口日记条数当成待办数显示 | 本轮实测 |
| H23 | **Puppeteer 入口路径**：`puppeteer-core@25` 用 `lib/puppeteer/puppeteer-core.js`，`lib/esm/...` 不存在 | 本轮导入失败 |
| H24 | **空态是合法状态**：`treatment#3`（无手术）、`life#0`（无造口）、`trials#1`（无收藏）不允许用假数据填充来"消除空态" | 本轮无头穷举 |
| H25 | **资料包口径必须写清 Cumulative 还是 year-scoped**：本包文件名带 2026 但覆盖 2003–2026 累计登记，必须在 manifest / README / CLINICAL-DATA 三处写明，2026 首次公示仅 14 条 | 本轮核对 manifest 时发现 |

### 3.4 肛管癌专属约束（依据 `docs/SPEC.md`）

| # | 约束 | 依据 |
| --- | --- | --- |
| A-A1 | **肛管鳞癌与肛缘鳞癌分开记录部位**（肛管 / 肛缘 / 不明），部位不自动推断 | SPEC A1 |
| A-A2 | **根治性放化疗是主线**（MMC/5-FU 或卡培他滨 + IMRT），手术是未控/复发后的路径；两条路径并存时**保留历史不覆盖** | SPEC A2 |
| A-A3 | **APR 与永久造口单独建档**，造口不是"手术并发症"附属项 | SPEC A3 |
| A-A4 | **肛周皮肤 RTOG 分级**按时间记录，固定标注"自查分级，不是医生评估" | SPEC A4 + 立场 |
| A-A5 | **排便功能用 Wexner 控便评分 + 排便日记**，不用通用「腹泻」页；里急后重、便血单列 | SPEC A5 |
| A-A6 | **四点位改为双侧腹股沟淋巴结短径**（`paired_measures`），缺一侧不生成差值；这是对家族四点位契约的**需评审偏差** | SCHEMA.md §3 |
| A-A7 | **一图秀默认**：体重 + 白蛋白双数值线 + 肛周皮肤 RTOG 分类节点（分类不连线） | SPEC §4 |
| A-A8 | **HPV 状态单列**（阳性 / 阴性 / 未知），未知不等于阴性；不做"是否由 HPV 引起"的归因 | SPEC A6 |
| A-A9 | 不做：治疗方案推荐、放疗剂量建议、皮肤用药推荐、造口产品品牌推荐、能否保肛判断、病友匹配、预后预测 | SPEC「明确不做」 |
| A-A10 | 临床试验只做**登记信息留档**：不排序、不打分、不预测入组可能；每条必须有来源 URL 与首次公示日期 | CLINICAL-DATA §对工作台页的约束 |
| A-A11 | 中国中心试验只反映登记中标注的站点，**不得表述为"国内可参加"** | CLINICAL-DATA 限制 3 |
