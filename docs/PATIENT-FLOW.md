# 患者流程（v0.1）

页面树由下面三条真实时刻反推，不从医生流程照搬。每条写「时刻 → 打开哪一页 → 得到什么产物」。

## 流程 A：放疗第 4 周，皮肤疼得坐不住

| 步骤 | 患者在做什么 | 打开哪里 | 得到什么 |
| --- | --- | --- | --- |
| 1 | 排便后擦拭疼，发现肛周破皮 | 看板 → 「记录今天」 | 一条症状草稿（部位/严重度/时间） |
| 2 | 想知道这算几级 | 肛周皮肤 → 分级记录 | 对照 RTOG 描述，记下"2 级 · 片状湿性脱皮" |
| 3 | 回忆这周怎么护理的 | 肛周皮肤 → 护理记录 | 坐浴时间、 barrier 霜、疼痛变化，一条时间序 |
| 4 | 不确定要不要提前找医生 | 肛周皮肤 → 何时联系医生 | 警戒信号清单（发热、脓性渗液、剧痛）→ 自己判断要不要联系 |
| 5 | 下次门诊想说清楚 | 复查与随访 → 问题清单 | "皮肤 6 月最重 3 级，现在结痂，还能坐浴吗？" |

产物：**一条可核对的分级记录 + 一个具体问题**。不产生"该怎么处理"的结论。

## 流程 B：放疗结束 3 个月，一天跑 4 次厕所

| 步骤 | 患者在做什么 | 打开哪里 | 得到什么 |
| --- | --- | --- | --- |
| 1 | 早上连着跑三趟，第二次很急 | 肠道与排粪 → 排便日记 | 次数 4、急迫 2/3、失禁 0、里急后重 1/3 |
| 2 | 想看看有没有变好 | 病情一图秀 | 排便次数线与皮肤分级节点并排，看到 6 月峰值、9 月回落 |
| 3 | 想知道"这算不算严重" | 肠道与排粪 → 控便评分 | Wexner 折算分 + 各维度组成（量表，不是诊断） |
| 4 | 复查前整理 | 检查与指标 → 血常规与生化 | 白蛋白 40.2、血红蛋白 125，参考区间对照 |
| 5 | 生成带去门诊的一页 | 复查与随访 → 生成复诊摘要 | 体重/白蛋白变化、未缓解症状、4 个问题 |

产物：**一页复诊摘要 + 一条趋势**。摘要明写"不是医生结论"。

## 流程 C：APR 术后 8 个月，造口周围发红

| 步骤 | 患者在做什么 | 打开哪里 | 得到什么 |
| --- | --- | --- | --- |
| 1 | 换底盘时发现皮肤红 2 cm | 造口与生活 → 造口日常 | 记录输出性状、渗漏次数、皮肤 1 级 |
| 2 | 想知道是不是换得太勤 | 造口与生活 → 日常清单 | 底盘中心孔、排空时机、渗漏先查贴合 |
| 3 | 不敢出门、怕鼓包 | 造口与生活 → 工作与社交 | 出门备用包清单；把担心写成 viewpoint |
| 4 | 伴侣关系受影响 | 造口与生活 → 亲密关系与生育 | 可在门诊开口的问题清单（不提供性行为建议） |
| 5 | 下次复查 | 复查与随访 → 复查节奏 | 造口门诊 + 肿瘤复查同一天，避免两次跑 |

产物：**造口日记 + 一条"我的看法"**（标注不是医生结论，不进趋势）。

## 页面树（由三条流程反推）

```
看板
├─ 记录今天（症状/排便/皮肤/造口）
├─ 下次复查提醒
└─ 三个要带去的问句
病情整理 ── 资料库 / 待核对候选 / 病情档案 / 指标与事件
我的分型 ── 病理与部位 / 分期与淋巴结 / HPV 与风险因素
治疗历程 ── 治疗路径 / 放疗与化疗 / 手术与造口 / 疗效评估
副作用与症状 ── 症状清单 / CTCAE 对照 / 就医边界
肠道与排粪 ── 排便日记 / 控便评分 / 里急后重与便血
肛周皮肤 ── 分级记录 / 护理记录 / 何时联系医生
检查与指标 ── 血常规与生化 / 肿瘤标志物 / 影像与内镜
病情一图秀 ── 数值曲线 / 分类与事件 / 数据口径
造口与生活 ── 造口日常 / 亲密关系与生育 / 工作与社交
心理支持 ── 情绪记录 / 病友与家属 / 求助路径
复查与随访 ── 复查节奏 / 本次复查准备 / 问题清单
临床研究 ── 2026 线索 / 已收藏 / 入组要问什么
```

## 三条流程共同的失败点（原型必须处理）

1. **记了但找不到**：记录入口必须在首屏，且当天可回看（看板 alert + 最近事件）。
2. **分级和感受混在一起**：分级是字段，感受是 viewpoint，两者不互相覆盖。
3. **带去门诊的东西太长**：摘要控制在一屏，问题按优先级只列 3–5 条。
