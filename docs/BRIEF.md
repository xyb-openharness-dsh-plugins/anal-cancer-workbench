# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：肛管癌（肛管鳞状细胞癌）患者与家属，含根治性放化疗期间、治疗后随访期、造口术后与复发转移阶段

场景：把散落在病历、化验单、影像报告和出院小结里的信息整理成一条可回看的时间线，重点照看放化疗期间的皮肤/肠道/血液学毒性、排粪与控便功能、造口护理与复查准备

核心流程：
1. 建立档案并导入或手工录入最近一次就诊资料
2. 在时间线上记录症状、化验与治疗事件，按 CTCAE 对照严重度
3. 带着整理好的问题清单和趋势图去复诊

完成结果：复诊前能在一页里说清最近 3 个月发生了什么、哪些症状在加重、有哪些问题要问医生

初始布局选择：business-first
