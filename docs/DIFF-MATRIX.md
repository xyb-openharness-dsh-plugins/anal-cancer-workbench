# 与样板癌种的差异矩阵（v0.1）

样板：`gastric-workbench v0.1.0` / `esophageal-workbench v0.1.0`（同一家族骨架）。
本表只记**刻意不同**的地方；相同部分（顶栏、AI 面板、一图秀工艺、3D 卡）见 `DEV-REQUIREMENTS` 第二节，默认照抄。

| # | 维度 | 胃癌 / 食管癌样板 | 肛管癌（本项目） | 为什么必须不同 | 落地位置 |
| --- | --- | --- | --- | --- | --- |
| D1 | 治疗主线 | 手术 + 围手术期化疗 / 根治性放化疗 | **放化疗是主线，手术是挽救**（APR） | 患者大部分时间在放疗毒性里，不在术后恢复里；把"手术"当第一路径会做错首页 | 治疗历程 · 路径卡 |
| D2 | 首页第一屏 | 进食/营养（食管）或术后饮食（胃） | **肛周皮肤 + 排便** | 放化疗期最影响坐、睡、出门的是皮肤与里急后重 | 看板 hero/alert |
| D3 | 营养页 | 独立"营养支持"页（食管） | **不设独立营养页**；体重/白蛋白并入检查与一图秀 | 肛管癌营养问题多为治疗期摄入不足，不需要单独入口；设了会稀释重点 | 检查与指标 + 一图秀 |
| D4 | 排便 | "腹泻"作为症状条目 | **独立「肠道与排粪」页**：次数/急迫/失禁/里急后重/Bristol + Wexner | "腹泻"一词盖不住放疗后的排便急迫与控便改变 | 一级页 6 |
| D5 | 皮肤 | 无独立页 | **独立「肛周皮肤」页**：RTOG 0–4 阶梯、湿性脱皮、护理记录 | 肛周湿性脱皮是最常见的剂量限制性毒性之一，是患者每天要面对的事 | 一级页 7 |
| D6 | 造口 | 无 | **「造口与生活」页**：造口日记、底盘渗漏、皮肤分级、亲密关系、工作社交 | APR 后永久造口改变每天的生活；只写"心理支持"等于没写 | 一级页 10 |
| D7 | 心理 | 独立"心理支持"页 | **保留独立「心理支持」页**（3 个二级页：情绪记录 / 病友与家属 / 求助路径），同时「造口与生活」继续保留亲密关系、身体形象、工作社交三个具体场景 | 用户 2026-10-21 明确「病友对心理的渴望还是挺明确的」，独立入口不能省；原方案担心"泛心理页会空转"，改为用**具体场景 + 自评量表 + 求助路径**填实，而不是取消入口 | 一级页 11 + 一级页 10 |
| D8 | 分型 | 病理 + 分段 + 分子 | **肛管 vs 肛缘**、AJCC 8th T/N（N1a/N1b/N1c）、HPV/HIV 分开 | 肛缘与肛管的分期与治疗不同；N 分区影响照射范围 | 我的分型 3 个二级页 |
| D9 | 随访 | 胃镜/吻合口 | **DRE + 双侧腹股沟触诊 + 肛门镜 + 盆腔 MRI** 四类分开 | 腹股沟淋巴结是肛管癌最常见的区域复发部位，单列才能不漏 | 复查与随访 |
| D10 | 四点位 | 乳腺癌上肢四点位 | **不适用**：无四肢四点位测量；契约改为「双侧腹股沟淋巴结短径，左右成对，缺一侧不生成差值」。2026-10-21 用户确认，口径参考 RECIST 1.1 短径测量法（≥15 mm 才作为病理性增大考虑） | 强行搬四点位会造出无意义字段；肛管癌的区域淋巴结评估本身就在腹股沟 | `paired_measures` + `v_paired_delta` |
| D11 | 临床研究 | 多通道离线语料（胰腺） | 仅 **ClinicalTrials.gov 在线**；其余三通道未配置，如实声明 | 离线语料只覆盖胰腺癌，对本癌种无覆盖 | research/README + 数据口径页 |
| D12 | 品牌色 | 小胃宝绿 / 小咽宝长春花蓝 | **小萌宝橙 #EE7B1E + 暖黄 #FFC220** | 用户提供的 logo 色系；只换 3 个变量 + 品牌字 | style.css 根变量 |
| D13 | 首页 AI 入口 | 有 | 有，但**默认收起**，文案强调"整理要点"而非"给建议" | 本癌种处置问题多，AI 的角色必须是整理而非决策 | 顶栏 / agent dock |

## 刻意保留（不因"换癌种"删掉）

| 保留项 | 理由 |
| --- | --- |
| 资料库四层事实 | 原件/候选/记录/指标不合并，是家族数据契约 |
| 一图秀双数值线 + 分类节点 | 患者能在 10 秒内指出"哪一段最难熬" |
| 3D 指标卡翻转迷你折线 | 单点不连线、分类不翻卡，避免误读 |
| 问题清单 + 复诊摘要 | 本癌种的核心产物：带去门诊的一页纸 |
| 临床试验"登记 ≠ 可入组"声明 | 防止把登记信息当成治疗机会 |

## 与"换名癌种"的自检

- 如果把本项目所有"肛管"替换成"直肠"，还剩什么？→ 皮肤页、造口页、排便急迫、腹股沟触诊、肛管 vs 肛缘，五项都不成立。
- 如果把皮肤页删掉，首页还剩下什么差异化？→ 只剩排便；因此皮肤页不可合并。
- 如果把造口页并进心理页，会丢什么？→ 底盘渗漏/皮肤分级/更换节奏三个可核对字段，全部丢失。
